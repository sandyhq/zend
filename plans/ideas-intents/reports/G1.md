## What was built
- A sidebar row **Ideas & Intents** under Search (`#sidebar-ideas`, ds/sidebar.luau `destinations` prop), opening Zend's own page `/plugin/zend/ideas` (ui/screens/ideas, page.luau). Same in the zend-v2 template's copies.
- Typed ideas: no title, project or chat; Save or Ctrl/⌘Enter; newest first.
- Voice memos: Record → Stop and save (max 60 s). The WAV and a `pending` record are written (temp, fsync, rename) to `<data>/ideas` **before** transcription; then local Parakeet (the model Settings → Voice downloads) fills the text. No model → `no_model`, failure → `failed` with the reason; audio kept in both, with Transcribe / Try again.
- Playback from the page, also after a restart (new `zend_voice::Playback`, cpal, nothing written).
- Composer dictation unchanged: `dictation.rs` only makes `MODEL` and `authorize()` `pub(crate)`.
- Test hook `ZEND_IDEAS_TEST_MIC=<wav>` (docs/reference/test-instance.md): records from a WAV in real time instead of the mic.

## Not tested
- **A real microphone and speakers**: no physical capture or listening. Playback is proven only to the ALSA sink's samples.
- macOS mic permission denial (`authorize()`): on Linux only the "can't open the mic" path ran.
- "Stop playing" seen live: the null sink isn't paced, so playback ended at once; covered by a unit test only.
- Luau UI tests (`zgx test ui`) and luau-lsp type checks: no zgx CLI here. The page's Luau ran through the Rust UI test and the stand-in only.
- Root workspace build/tests: zend-voice changes are additive (`mod play`, `pub use Playback`, crate-private `convert`); `crates/ui` (depends on it) not rebuilt.
- Windows/macOS builds.

## Notes and risks
- A memo's transcription loads its own Recognizer, apart from dictation's: both loaded at once costs the model's memory twice for a moment; the memo's is let go after 60 s idle.
- If the mic disconnects mid-recording, the partial audio is lost (Capture's finish behaviour); nothing half-written is left.
- `ZEND_IDEAS_TEST_MIC` is read by the shipping binary; it only changes Ideas' source and is documented as test-only.
- An earlier test job (`ii-test2`, `cargo test ideas`) was left on the AI build server before the build location changed; it could not be stopped without SSH.
