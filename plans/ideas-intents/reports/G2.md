## Findings

### P1 — Failed Save destroys the typed draft
Path: `apps/zgx/ui/screens/ideas/init.luau:48–55`.
`save()` clears the editor before the asynchronous add succeeds. An ordinary disk/permissions failure leaves neither the idea nor the draft; the toast cannot recover its words.

Reproduced through the shipping debug binary in an isolated offscreen local Podman container:
1. Click `#sidebar-ideas`.
2. Set `ideas_draft` to `DO NOT LOSE THIS` through the inspect socket (equivalent editor state).
3. `chmod 555 /probe/data/ideas` as the container's unprivileged user, after Store has opened it.
4. Click `#ideas-save`.
5. Inspect `ideas_draft`: `screens/ideas/init.luau::ideas_draft = ""`; textbox is empty, Save disabled, `#ideas-empty` still visible; no idea was added.

Recommendation: clear only on successful persistence, preserving any newer edit made while the request was pending. Add a UI regression test with a deliberately unwritable store.

### P1 — Navigating away hides an active recording without stopping it
Paths: `apps/zgx/src/ideas.rs:575–587` (window-lifetime capture polling); `apps/zgx/ui/screens/ideas/init.luau:62–149,303–384` (record controls confined to Ideas).

Reproduced in the same container with synthetic WAV capture, not a physical microphone:
1. Supply a ~23-second synthetic WAV via `ZEND_IDEAS_TEST_MIC` (repeat the existing 3.8-second speech fixture six times).
2. Click `#ideas-record`, then `role:checkbox "Settings"`.
3. Inspect shared `ideas`: `recording.phase = "recording"`, initially seconds 0 and later **10**.
4. Tree lookup `#ideas-page` returns `nothing matches`; the sidebar and all Ideas capture controls are gone. No app-wide capture indication/Stop replaces them.

The real microphone source is driven by the same window-lifetime recorder and stop flag. Continued physical capture is inferred from that code, not measured. This permits unintentionally retaining speech after leaving the capture surface (up to 60 seconds).
Recommendation: either stop/save on leaving, or retain an unmistakable global recording indicator with Stop/Discard. Add a navigation regression test. Background capture need not be prohibited, but cannot be invisible.
