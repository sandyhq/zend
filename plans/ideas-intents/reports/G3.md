# G3 report: corrections after G2

Key: `ideas-intents/G3/1` · Branch `ideas-intents` · Code commit: eb17e29b5 (this report follows in its own commit)
Fixes both P1 findings of [G2.md](G2.md). Scope: `apps/zgx/src/ideas.rs`, `apps/zgx/ui/screens/ideas/init.luau`, tests, one sentence each in CHANGELOG.md and docs/features.md.

## What changed
| Finding | Fix |
|---|---|
| A failed Save wipes the draft | `save()` clears the box only after `ideas.call add` succeeds, and only if the draft still equals what was sent (an edit made while it saved stays). Save is disabled while a save is in flight. |
| Leaving the page keeps recording unseen | An effect on the route (`route.current`) calls `ideas.call here` on the Ideas page and `leave` anywhere else. The page view's cleanup also calls `leave`. `Service::leave()` stops a recording and saves what was heard up to that point. It lets go of one still `starting` (nothing kept) and sets `away`, so `record_start` is refused ("Open Ideas & Intents to record a memo") until `here`. The real `microphone()` doesn't open the device if it was stopped before it began. |

The route is used rather than the view's lifetime because the page can stay built under Settings.

## Reproduction before the edit (observed)
These ran on the G1 binary with the G1 Luau. The window was the real offscreen one (`ZGX_OFFSCREEN=1`, inspect socket) in local rootless Podman. Its mic was `ZEND_IDEAS_TEST_MIC`, a 22.6 s synthetic WAV. Script: `~/.cache/zend-ideas-g3/stand.sh`.
- F1: click `#sidebar-ideas`, `chmod 555 data/ideas`, type "DO NOT LOSE THIS", click `#ideas-save`. Result: `ideas_draft = ""`, the box shows the placeholder, nothing on disk.
- F2: click `#ideas-record`, wait 1.2 s, click `role:checkbox "Settings"`. 4 s later the state is `recording {phase: recording, seconds: 5}`, and `#ideas-page` is not on screen.

## Not tested

- An edit typed while a save is in flight. The host answers within one frame in tests and in the window, so the case was not reached; the equality check covers it by code.
- `zend-voice` (unchanged since G1, 21 passed then), the zend-v2 template (no G3 change to its copies), and macOS/Windows.
